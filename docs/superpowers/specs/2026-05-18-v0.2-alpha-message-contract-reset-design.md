# Lingyia v0.2-α · Message Contract Reset · Design

> **Date**: 2026-05-18
> **Status**: Draft v2 (incorporates codex review feedback on 15 spec-level gaps)
> **Scope**: First sub-PR of v0.2 contract reset. Introduces Message/ContentBlock abstraction + Capability registry. Breaking change to v0.1 RunState — `schema_version` 1 → 2; v1 snapshots rejected on load.
> **Dependency**: None (foundation for v0.2-β and v0.2-γ)
> **Repository**: `/Users/yuchen/Documents/lingyia` (HEAD `6391ff47` = v0.1.0)

---

## 1. Background

Lingyia v0.1.0 (105 tests passing, alpha status) uses a "goal: str + observations + feedback" model for the agent loop. `Decision.content: str` is plain string. `RunState` carries no `Message` concept; `AnthropicModel` adapter currently reconstructs multi-turn assistant tool_calls history from observations.

This model breaks when scaling to:
- Multimodal input/output (image/audio blocks need first-class representation)
- Reasoning blocks (Anthropic encrypted thinking)
- Multi-turn chat persistence at framework level (not adapter-reconstructed)
- MCP integration (depends on structured content parts)
- Tool lifecycle hooks (γ depends on structured representation)

V0.2-α introduces the foundation: **messages as source of truth + content blocks + capability registry**. Subsequent sub-PRs build on this:
- **v0.2-β**: Token-level streaming, Session/thread API, Durable execution, Public telemetry fan-out
- **v0.2-γ**: Typed RunContext[Deps], Tool lifecycle hooks, Structured output validation/retry, HITL interrupt/resume first-class API

## 2. Goal

- Replace `RunState.goal/observations/feedback` with `RunState.messages: list[Message]` as the conversation source of truth
- Introduce `ContentBlock` discriminated union (Text/ToolUse/ToolResult/Image/Audio/Thinking) supporting multimodal + reasoning
- Add `ModelCapabilities` registry as a `Model` protocol property
- Bump `RUN_STATE_SCHEMA_VERSION` 1 → 2; reject v1 snapshots at load time
- Rewrite 4 adapters (OpenAICompatibleModel + OpenAIModel/SiliconFlowModel/MiniMaxModel/AnthropicModel) against the new contract
- Provide one-shot migration helper `lingyia_kit.migrations.v01_to_v02` for users with v1 checkpoints
- Public exports updated; downstream projects (e.g., the user's ai-agent backend pinned to `6391ff47`) must explicitly migrate

## 3. Non-goals (deferred to β/γ)

- ❌ Token-level streaming (β)
- ❌ Session/thread API + auto aload/asave (β)
- ❌ Durable execution semantics (β)
- ❌ Public multi-sink telemetry fan-out (β)
- ❌ HITL interrupt/resume first-class API (γ)
- ❌ Typed `RunContext[Deps]` (γ)
- ❌ Tool lifecycle hooks (γ)
- ❌ Structured output validation/retry (γ)
- ❌ MCP support (v0.3)
- ❌ RedactedBlock (codex correctly flagged: redaction is sink-side concern, not content-layer — keep `RegexRedactor` as telemetry filter, do not surface redaction as semantic content the model sees)

    ASSISTANT = "assistant"

### 4.2 ContentBlock — dataclass discriminated union

`type` literal field is the JSON discriminator. `_block_from_dict()` factory dispatches on `type`. **No Pydantic dependency** (preserves lingyia's "zero deps beyond httpx" philosophy).

```python
from dataclasses import dataclass, field
from typing import Any, Literal, Mapping, Union

@dataclass(frozen=True)
class TextBlock:
    text: str
    type: Literal["text"] = "text"

@dataclass(frozen=True)
class ToolUseBlock:
    id: str
    name: str
    input: Mapping[str, Any]
    type: Literal["tool_use"] = "tool_use"

@dataclass(frozen=True)
class ToolResultBlock:
    tool_use_id: str
    content: Union[str, tuple["ContentBlock", ...]]
    is_error: bool = False
    type: Literal["tool_result"] = "tool_result"

@dataclass(frozen=True)
class ImageSource:
    """One of: url (remote), or data+media_type (inline base64)."""
    url: str = ""
    data: str = ""           # base64-encoded if inline
    media_type: str = ""     # e.g. "image/png" — required when data set

@dataclass(frozen=True)
class ImageBlock:
    source: ImageSource
    type: Literal["image"] = "image"

@dataclass(frozen=True)
class AudioSource:
    url: str = ""
    data: str = ""
    media_type: str = ""     # e.g. "audio/mp3"

@dataclass(frozen=True)
class AudioBlock:
    source: AudioSource
    type: Literal["audio"] = "audio"

@dataclass(frozen=True)
class ThinkingBlock:
    """Reasoning trace, Anthropic-specific. Not user-visible text."""
    thinking: str
    signature: str = ""      # Anthropic encrypted signature for signed thinking
    type: Literal["thinking"] = "thinking"

ContentBlock = Union[
    TextBlock,
    ToolUseBlock,
    ToolResultBlock,
    ImageBlock,
    AudioBlock,
    ThinkingBlock,
]
```

**Validation rules** (raised as `ValueError` at construction or `from_dict` time):
- Unknown `type` field in `from_dict` payload → `UnknownBlockTypeError(type_value)`
- Missing required field per block class → `ValueError("missing required field: <name>")`
- `Role` parse from string fails → `ValueError("invalid role: <value>")`
- `Mapping` inputs (e.g., `ToolUseBlock.input`) must be JSON-serializable; non-JSON values raise at serialization time
- `ToolResultBlock.content: tuple[ContentBlock, ...]` is recursive; `from_dict` recurses; cycles forbidden (depth-limit raise at depth > 8)

### 4.3 Message

```python
@dataclass(frozen=True)
class Message:
    role: Role
    content: tuple[ContentBlock, ...]

    def to_dict(self) -> dict[str, Any]:
        return {
            "role": self.role.value,
            "content": [_block_to_dict(b) for b in self.content],
        }

    @classmethod
    def from_dict(cls, data: Mapping[str, Any]) -> "Message":
        return cls(
            role=Role(data["role"]),
            content=tuple(_block_from_dict(b) for b in data.get("content", [])),
        )
```

### 4.7 CapabilityPolicy + CapabilityMismatchError

```python
class CapabilityMismatchError(RuntimeError):
    def __init__(
        self,
        required: frozenset[BlockKind],
        accepted: frozenset[BlockKind],
        unsupported: frozenset[BlockKind],
        model_id: str,
    ):
        self.required = required
        self.accepted = accepted
        self.unsupported = unsupported
        self.model_id = model_id
        super().__init__(
            f"Model {model_id!r} does not accept blocks: {sorted(unsupported)}. "
            f"Required: {sorted(required)}; accepted: {sorted(accepted)}."
        )


@runtime_checkable
class CapabilityPolicy(Protocol):
    """How to handle capability mismatch before model.adecide()."""

    def apply(
        self,
        messages: list[Message],
        capabilities: ModelCapabilities,
    ) -> list[Message]:
        """Return messages compatible with capabilities. May raise."""
        ...


class FailFastCapabilityPolicy:
    """Default: raise CapabilityMismatchError if any required block kind unsupported."""

    def apply(self, messages, capabilities):
        required = _collect_block_kinds(messages)
        unsupported = required - capabilities.accepts
        if unsupported:
            raise CapabilityMismatchError(
                required=required,
                accepted=capabilities.accepts,
                unsupported=unsupported,
                model_id=capabilities.model_id,
            )
        return messages
```

Core ships `FailFastCapabilityPolicy` only. `TextOnlyDowngradePolicy` and other graceful-degrade policies belong in `lingyia_kit` (deferred — α only ships the contract; kit policies follow as needed).

When a downgrade policy is applied, it MUST emit a `TelemetryEvent(kind="capability_downgraded", payload={...})`.

`Runtime.production(..., capability_policy: CapabilityPolicy = FailFastCapabilityPolicy())`.

### 4.8 Decision (content is blocks; kind is control signal)

```python
@dataclass(frozen=True)
class Decision:
    kind: DecisionKind                     # CALL_TOOL / FINAL_ANSWER / ASK_HUMAN / ABORT — control signal
    content: tuple[ContentBlock, ...] = ()
    usage: Optional[ModelUsage] = None

    @property
    def tool_calls(self) -> tuple[ToolUseBlock, ...]:
        return tuple(b for b in self.content if isinstance(b, ToolUseBlock))

    @property
    def text(self) -> str:
        """Concatenated user-visible text from TextBlocks only.
        Does NOT include ThinkingBlock content."""
        return "".join(b.text for b in self.content if isinstance(b, TextBlock))

    @classmethod
    def call_tools(cls, blocks: Sequence[ToolUseBlock]) -> "Decision":
        if not blocks:
            raise ValueError("call_tools requires at least one ToolUseBlock")
        return cls(kind=DecisionKind.CALL_TOOL, content=tuple(blocks))

    @classmethod
    def final_answer(cls, content: Sequence[ContentBlock]) -> "Decision":
        return cls(kind=DecisionKind.FINAL_ANSWER, content=tuple(content))

    @classmethod
    def ask_human(cls, question: str) -> "Decision":
        # Stored as TextBlock so decision.text accessor still works
        return cls(kind=DecisionKind.ASK_HUMAN, content=(TextBlock(text=question),))

    @classmethod
    def abort(cls, reason: str) -> "Decision":
        return cls(kind=DecisionKind.ABORT, content=(TextBlock(text=reason),))
```

`ASK_HUMAN` and `ABORT` remain as `Decision.kind` (control signal, NOT pushed into messages). Runtime maps `ASK_HUMAN` → `state.interrupt = Interrupt(reason=QUESTION, message=decision.text)`.

### 4.9 RunState (clean break, schema_version = 2)

```python
RUN_STATE_SCHEMA_VERSION = 2

@dataclass
class RunState:
    """Source of truth for the agent run.

    v0.2 break: messages list replaces goal+observations+feedback entirely.
    """
    messages: list[Message]
    run_id: str = field(default_factory=lambda: str(uuid4()))
    iteration: int = 0
    trace: list[TelemetryEvent] = field(default_factory=list)
    interrupt: Optional[Interrupt] = None
    metadata: dict[str, Any] = field(default_factory=dict)
    schema_version: int = RUN_STATE_SCHEMA_VERSION

    def to_dict(self) -> dict[str, Any]: ...
    @classmethod
    def from_dict(cls, data: Mapping[str, Any]) -> "RunState":
        version = data.get("schema_version", RUN_STATE_SCHEMA_VERSION)
        # v0.2-α: reject BOTH older (< 2) and newer (> 2) snapshots
        if version != RUN_STATE_SCHEMA_VERSION:
            raise UnknownSchemaVersionError(
                f"snapshot schema_version={version} not loadable by runtime "
                f"version={RUN_STATE_SCHEMA_VERSION}. Use lingyia_kit.migrations.v01_to_v02 "
                f"to upgrade v0.1 snapshots."
            )
        return cls(
            messages=[Message.from_dict(m) for m in data.get("messages", [])],
            run_id=data["run_id"],
            iteration=data.get("iteration", 0),
            trace=[...],
            interrupt=_interrupt_from_dict(data.get("interrupt")),
            metadata=dict(data.get("metadata", {})),
            schema_version=version,
        )
```

**Removed fields**: `goal: str`, `observations: list[Observation]`, `feedback: list[str]`. These are encoded as messages.

## 5. Runtime Message Lifecycle Rules (G1)

The runtime mutates `state.messages` at these transitions:

| Transition | New message appended | Role |
|---|---|---|
| `model.adecide()` returns `Decision(kind=CALL_TOOL, content=...)` | `Message(ASSISTANT, decision.content)` — contains TextBlock + ToolUseBlock | ASSISTANT |
| `model.adecide()` returns `Decision(kind=FINAL_ANSWER, content=...)` | `Message(ASSISTANT, decision.content)` | ASSISTANT |
| Executor completes tools → ToolResult per call | One `Message(USER, (ToolResultBlock(tool_use_id=cid, content=output, is_error=not ok),))` per tool | USER |
| Guard denies a tool call (pre-execution) | `Message(USER, (TextBlock(f"Guard rejected tool {name}: {reason}"),))` | USER |
| Validator rejects model output | `Message(USER, (TextBlock(f"Validator rejected: {reason}"),))` | USER |
| Approval rejection (human said no) | `Message(USER, (TextBlock(f"User rejected the action: {reason}"),))` | USER |
| Human resume from ASK_HUMAN | `Message(USER, (TextBlock(human_input),))` | USER |

Decision kind ASK_HUMAN / ABORT do NOT append messages — they set `state.interrupt` or terminate the run.

System messages (from `Harness.system_prompt`) are prepended as `Message(SYSTEM, (TextBlock(prompt),))` at run start IF not already present.

## 7. ToolCall vs ToolUseBlock coexistence (G3)

Two abstractions serve distinct purposes:

- **`ToolUseBlock`**: transcript representation. Appears in `Decision.content` and `Message.content`. Public API surface for adapters and serialization.
- **`ToolCall`**: execution-internal representation. Consumed by `ToolExecutor.run()`. NOT part of the public transcript.

`Runtime` converts `Decision.tool_calls` (i.e., `ToolUseBlock`s) → `ToolCall` instances when dispatching to executor:

```python
def _block_to_call(block: ToolUseBlock) -> ToolCall:
    return ToolCall(name=block.name, args=dict(block.input), call_id=block.id)
```

`ToolCall` keeps current shape (existing tests for executor still consume it).

## 8. ToolResult vs ToolResultBlock (G4)

- **`ToolResult`**: tool handler return type (existing dataclass). Unchanged.
- **`ToolResultBlock`**: transcript representation. New in v0.2-α.

Runtime converts after executor finishes:

```python
def _result_to_block(result: ToolResult, tool_use_id: str) -> ToolResultBlock:
    if result.ok:
        content = _serialize_output(result.output)  # str OR tuple[ContentBlock,...]
    else:
        content = result.error
    return ToolResultBlock(
        tool_use_id=tool_use_id,
        content=content,
        is_error=not result.ok,
    )
```

`_serialize_output` rules:
- `str` output → keep as `str`
- `dict` or non-string → `json.dumps(output, ensure_ascii=False)` as `str`
- Tool authors who want rich content can return `ToolResult(output=tuple_of_blocks, ...)` — passed through as `tuple[ContentBlock,...]`

## 13. Checkpointer schema rejection (G9)

Migration function maps:
- `goal: str` → prepended as `Message(USER, (TextBlock(goal),))`

## 15. OpenAI ToolResultBlock flattening rule (§D3)

OpenAI `role="tool"` message expects `content: str`. When the lingyia `ToolResultBlock.content` is `tuple[ContentBlock, ...]` (nested blocks), adapter flattens:

```python
def _flatten_tool_result_for_openai(content) -> str:
    if isinstance(content, str):
        return content
    text_parts = []
    json_fallback = []
    for block in content:
        if isinstance(block, TextBlock):
            text_parts.append(block.text)
        else:
            # Non-text blocks: JSON-serialize and append as text
            json_fallback.append(json.dumps(_block_to_dict(block), ensure_ascii=False))
    return "\n".join(text_parts + json_fallback)
```

Documented as adapter-specific compatibility. Anthropic adapter passes nested content through natively.

## 16. ThinkingBlock policy (§D4)

- `ThinkingBlock` is in `ContentBlock` union
- NOT included in `Decision.text` accessor
- Persists in checkpoint serialization (it's conversation state Anthropic needs to see in resume)
- Capability-gated: only adapters declaring `BlockKind.THINKING` in `capabilities.emits` may return a Decision containing ThinkingBlock. Currently only `AnthropicModel`.
- Runtime rejects with `CapabilityViolationError` if a non-Anthropic model attempts to emit ThinkingBlock (defensive check, primarily for testing)
- `ThinkingBlock.signature` carries Anthropic's encrypted thinking signature when applicable

| `ImageSource` neither `url` nor `data+media_type` set | `ValueError("ImageSource requires url or data+media_type")` |
| `AudioSource` neither `url` nor `data+media_type` set | `ValueError("AudioSource requires url or data+media_type")` |
| Empty `Message.content` tuple | `ValueError("Message.content must be non-empty")` |

## 21. Risks + Mitigations

| Risk | Mitigation |
|---|---|
| ai-agent backend will break at upgrade time | Documented explicit migration path (§18); ai-agent stays on pin until ready |
| 4 adapter rewrites is a lot of surface area | Split adapter migrations into reviewable sub-commits within the α PR; e.g. base adapter first, then each provider |
| Migration helper edge cases (v0.1 observations without `call_id`) | Best-effort migration; log warnings; document caveats. Users with critical v0.1 data can manually fix the migrated dict before loading |
| ThinkingBlock in checkpoint could leak Anthropic-specific data into non-Anthropic resume | Capability-gated emit + adapter responsibility to strip ThinkingBlock when sending to non-emitting models on resume |
| OpenAI adapter ToolResultBlock flattening loses nested block fidelity | Documented as adapter-specific; users who need fidelity should use Anthropic provider |
| Public re-exports introduce circular-import risk | `Message`/blocks/capability all in `lingyia_core/state.py` + `capability.py` (no cross-imports); `__init__.py` purely re-exports |
